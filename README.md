The Souk – Online Second-Hand Marketplace
Project by: A team of 3 students during our exchange semester at the University of California, Irvine (UCI)

Overview
The Souk is a modern, feature-rich web application for buying and selling second-hand items. Built using the Vue.js framework and supported by RESTful APIs, the platform simulates a real-world online marketplace with an emphasis on simplicity, speed, and sustainability.

This project was developed as part of our coursework during our semester abroad at UCI and is designed to promote reuse and reduce waste through tech innovation.

Tech Stack
Frontend
Vue.js 3 (with Vue Router and Vuex for state and routing management)

HTML & CSS for layout and styling

JSON for data persistence (initial mock data)

Backend (Simulated via Local JSON/API)
Express.js for handling HTTP requests

CORS and dotenv for environment/config support

JSON files as mock databases

# the-souk IMPORTANT

## Project setup ( with the cmd, go in the location of your folder "the-souk")
```
npm install
```

### Compiles and hot-reloads for development ( run the front-end and the back-end simultaneously)
